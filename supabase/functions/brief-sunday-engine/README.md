# Sunday newsroom engine v2

Pipeline: sources -> observations -> candidates -> editorial ranking -> memory -> quality gate -> publish.

Rules:
- Five-minute cron is a check cadence, never a publication quota.
- Source acquisition failures cannot abort editorial evaluation.
- Maude requires quantitative evidence.
- Same source is not the definition of duplication; premise similarity and persistent premise memory are.
- Reusable prose templates are rejected by the quality gate.
- A cycle may publish nothing.
